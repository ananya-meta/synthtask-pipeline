# AGENTS.md — working on this repo

This file governs agents working **on the harness**. It is not read during idea
generation: isolation roots under `runs/` receive only seed material.

## What this repo is

An ideation pipeline for the AAI *Research Papers to Tasks* track. It takes a research
paper and produces ranked, deduplicated, human-adjudicated **task ideas**. It deliberately
stops before scaffolding — no Dockerfiles, no tests, no Smoldata submission.

## Authorship boundary — read before editing

The track allows **Codex and TBH only; no Claude**, and requires that no third-party model
tokens reach agent-facing task files.

| Path | Who may write it |
|---|---|
| `ideation/**` | any agent — orchestration only, never ships in a task |
| `prompts/**` | **Ananya only** (human) |
| `config/antipatterns.json` | Ananya; seeded from the track doc |
| `seeds/*/ASSUMPTIONS.md` | Ananya |
| `seeds/*/paper.md`, `abstract.md`, `meta.json` | generated by `ideation seed add` |
| `runs/**` | written by Codex/TBH at generation time |

If you are Claude: do not write prompts, rubric criteria, task ideas, or anything that
shapes what tasks come out. Harness code is fine.

## Invariants

1. **Isolation is load-bearing.** Each generation run gets a fresh root containing only
   `abstract.md`, `paper.md`, `ASSUMPTIONS.md`. `generate.assert_isolated()` enforces this.
   Never widen `SEED_FILES` to include corpus data, another generator's output, or prior
   ideas — that silently invalidates every Codex-vs-TBH comparison in the DB.
2. **Rejected ideas are never deleted.** They carry the reason codes the judge is measured
   against.
3. **Prompt and rubric versions are content hashes.** Editing a prompt starts a new
   tracked generation rather than mutating history.
4. **Stdlib only.** No third-party runtime dependencies — the tool must run with system
   Python and no venv.

## Layout

```
ideation/   db · seeds · generate · dedup · judge · review · report · cli
prompts/    human-authored (see prompts/README.md)
seeds/NN-slug/   abstract.md · paper.md · ASSUMPTIONS.md · meta.json
runs/<seed>/<generator>/<ts>/   isolation roots
config/antipatterns.json
data/ideation.db
```

## Conventions

- Trailing newline on every file; unix line endings.
- Comment only non-obvious invariants and external constraints. Do not restate the code,
  and do not explain a change inline — that belongs in the commit message.
- `runs/` and `data/*.db` are gitignored; the corpus is local state, not source.
